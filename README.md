# Ahad of the Curve (AOTC)

Restores original Skullgirls 2nd Encore content.

## What it restores
- Filia story cutscenes
- Digital Art Compendium
- Big Band story cutscenes
- Double story cutscenes
- Beowulf story cutscenes
- Parasoul story cutscenes
- Black Egrets
- Parasoul's armbands
- Original combo callouts
- Eliza cutscenes
- Mike Z's Soviet voice pack *(optional)*

AOTC never edits the game's own archives. Everything can be undone.

## Download
Get the latest version from **[Releases](../../releases/latest)**. Pick **one** method:

| Download | Use it if |
|---|---|
| `AOTC-<version>-Standalone.zip` | You don't use a mod manager |
| `AOTC-<version>-ModManager.zip` + optional `AOTC-<version>-ModManager-Optional-soviet.zip` | You use [Skullgirls Mod Manager](https://github.com/Anonnie04/skullgirls-mod-manager) |

Never use both methods on the same game.

## Install: standalone
1. Close Skullgirls.
2. Extract the ZIP anywhere (your Desktop is fine).
3. Double-click `AOTC.cmd` and choose **[1] Restore**.
4. Answer `Restore Mike-Z's Soviet Voice? Y/N`.
5. Launch Skullgirls through Steam. The first launch takes longer while SkullLoader builds its cache.

**Undo:** run `AOTC.cmd` again and choose **[2] Re-censor**.

## Install: Skullgirls Mod Manager
Get Anonnie04's **Skullgirls Mod Manager** from its [GitHub releases](https://github.com/Anonnie04/skullgirls-mod-manager/releases/latest) first.

1. **Import mod** and choose `AOTC-<version>-ModManager.zip`.
2. One time only, open **Backups & tools → Set up mod support** and select the Standalone ZIP. It contains the required `CoreMessaging.dll`.
3. *(Optional)* **Import mod** `AOTC-<version>-ModManager-Optional-soviet.zip` for the original Soviet announcer.
4. Tick the mods, click **Preview changes**, then **Apply enabled mods**.

**Undo:** untick the mods and apply, or use **Restore originals**.

## Good to know
- Made for the Steam version of Skullgirls 2nd Encore current as of October 2026. If Skullgirls updates, AOTC refuses to install rather than guess. Run Re-censor before verifying game files in Steam.
- See [CHANGELOG.md](CHANGELOG.md) for what changed in each version.
